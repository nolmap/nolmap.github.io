놀맵 — 신도림놀구로 안전지도

청소년이 놀구로에 오고 가는 길의 안전 경로, 위험 구간, 구로엔젤 가게, 삼대발견 장소를 한눈에 볼 수 있는 웹앱이에요. 지금 보고 있는 이 지도가 이정표 청소년들이 만든 거예요!

카카오맵 API 길찾기 기능 구로엔젤 핀 삼대발견 핀 Cloudflare
1
AI 공공교육

AI와 코딩의 기초부터 배우며 웹앱 개발의 기반을 다져요.

2
안전지도 웹앱 개발 · 배포

놀맵을 직접 코딩하고 GitHub Pages로 배포해요. 오류를 찾고, 기능을 추가하고, 개선합니다.

3
이동경로 데이터 수집

실제로 걸어보며 안전한 경로와 위험 구간을 직접 확인하고 지도에 반영해요.

4
지속적인 업데이트

구로엔젤 가게 정보, 삼대발견 장소 등 최신 정보로 계속 업데이트해요.
