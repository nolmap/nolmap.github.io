✏️ 소개글 · 사진 수정

구로엔젤과 삼대발견의 소개글과 사진을 고쳐서 GitHub에 바로 저장해요. 저장하고 1~2분 뒤 놀맵에 반영돼요.

토큰 만드는 법
  1. GitHub → 오른쪽 위 프로필 → Settings → 맨 아래 Developer settings
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. Resource owner: nolmap, Repository access: Only select repositories → nolmap.github.io
  4. Permissions → Repository permissions → Contents: Read and write
  5. 만들어진 github_pat_... 값을 위 칸에 붙여 넣기

토큰은 이 브라우저에만 저장돼요. 공용 컴퓨터에서는 다 쓰고 꼭 "연결 해제"를 눌러 주세요.
